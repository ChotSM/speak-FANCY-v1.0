# Speak FANCY

Static GitHub Pages build of the Speak FANCY speaking-practice app.

## This update

The Part 2 checker now evaluates response quality through:

- fulfilment and development of all four prompts;
- relevance, clarity and logical consistency;
- accurate use of TAD–REES;
- grammar and sentence control;
- appropriate and varied vocabulary;
- code-switching, repetition and vague pronoun detection;
- unsupported Research claims;
- coherence and overall communicative effectiveness.

Response length alone does not increase a learner's band.

## Publish on GitHub Pages

Upload `index.html` and this `README.md` to the repository root, commit the changes, and keep GitHub Pages set to deploy from the `main` branch and root folder.

The assessment is an automated indicative practice estimate, not an official SPM examination result.
